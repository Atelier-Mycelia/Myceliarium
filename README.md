# Myceliarium: Control Panels Made Easy!
This is a Unity editor-tooling framework for building RPG Maker-style database editors using UI Toolkit. Instead of manually wiring together complex editor windows, Myceliarium provides reusable control-panel building blocks that help you create structured editor tooling with less boilerplate and more ease of extension.

## ✨ Features
- Designer-friendliness as per being built on Unity UI Toolkit (not IMGUI!)
- Enables RPG Maker-style database editing workflows
- Reusable control-panel architecture that cuts down on boilerplate
- Supports complex editor tooling
- Designed with extensibility in mind
